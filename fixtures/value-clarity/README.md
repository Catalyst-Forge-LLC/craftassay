# Value-clarity calibration

Run the installed skill on each supplied subject, without its expected file in context. Compare the result afterwards. These are manual behavioral cases, not executed model tests.

## Lint an XLIFF file

For localization engineers reviewing XLIFF 2.0 files. This command-line linter reads an XLIFF file and writes diagnostics so you can fix invalid entries before import. Install the supplied package, run `xliff-check sample.xlf --out diagnostics.txt`, read that file, and stop. The fixture defines this as its complete procedure.

## Stopwatch

A browser timer. Press Start to begin elapsed time, Pause to keep the current time, and Reset to return to zero. Stop when you have the duration you need.

## Restore every file

This recovery tool restores every file, guaranteed.

Procedure: choose a folder, run the supplied inventory command `recover list ./folder --out candidates.txt`, read the candidate list, and stop. This command only lists candidates. It does not restore files.

## A useful formatter

This formatter is useful. Install the supplied package. Run `format-note input.md --out formatted.md`. Read formatted.md, which contains the formatted copy. The input is unchanged. Stop. The fixture defines this as the complete workflow.

## Review a release checklist

For maintainers handing a release to a colleague. This agent skill reads checklist.md and writes review.md with missing commands and contradictions, so you can repair the handoff. Install the supplied skill folder in your agent, ask it to review checklist.md and write review.md, then read the report and stop. It does not edit the checklist. Example: an unnamed launch command becomes a finding asking you to name the command and expected screen.
