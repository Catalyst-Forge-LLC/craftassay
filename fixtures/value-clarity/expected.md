# Expected review behavior

- Specialist: explicit audience and setup. No penalty for justified domain terminology.
- Stopwatch: inferable benefit is sufficient. No mandatory marketing finding.
- Recovery guarantee: one Accuracy claim-risk finding, referenced under Clarity if needed. No double-counting.
- Formatter: distinguish weak public relevance from the useful bounded workflow. Do not claim a runtime failure or low demand.
- Checklist: a clean value assessment is allowed. No invented defect.

Each applicable review records seven statuses with sources in coverage.md, includes Value as presented in report.md, and produces the same four artifacts. Do not assign an aesthetic score from these text-only fixtures. For an older baseline, disclose the rubric change rather than crediting it as a product improvement.
