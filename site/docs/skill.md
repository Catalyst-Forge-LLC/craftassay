The product is one folder. An agent reads it and writes the report.

`SKILL.md` plus the reference files it reads. No folder yet? [Install](/docs/install).

## What the agent does

1. Locate the subject (a project, site, skill, spec, portfolio, or a paste).
2. Establish the intended audience and included surfaces.
3. Inspect the discovery-to-first-use path and consequential claims.
4. Write `report.md`, the scorecard, findings, and coverage. Hand them over. Do not edit the subject.

A later pass with the earlier report attached is a comparison.

## Example prompts

- CraftAssay review of this site.
- Review this README using CraftAssay.
- Compare this landing page against the attached baseline review.
- Score this skill on the seven CraftAssay dimensions.

It runs when you name it, or when a presentation needs an evidence-backed critique. The report does not rewrite the source. Not for Cold-eye readiness, line editing, or implementing findings.
