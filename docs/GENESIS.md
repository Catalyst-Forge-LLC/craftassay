# CraftAssay — what, not how

The portable product spec is the review contract at repo root:

**[CraftAssay Review and Comparison Specification v1.1](../craftassay-review-spec-v1.1.md)**  
Scoring rubric v1.0. Default mode: presentation and product-concept review.

That document defines identity, scope, evidence, the seven dimensions, findings, report structure, comparison, and the reusable invocation. It does not claim that an application, CLI, or hosted service already exists.

Delivery shape (skill, FilePress site, LocalSlip, LocalHelm) lives in [`PHASE_1_BRIEF.md`](./PHASE_1_BRIEF.md). If those files disagree on review behavior, the specification wins.
