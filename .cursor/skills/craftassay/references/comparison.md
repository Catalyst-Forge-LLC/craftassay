# Comparison

Use this file when an earlier matching CraftAssay review is
supplied or found locally. Follow `output.md`. An explicit
request to compare different subjects is allowed. Write the
comparison into a **new** run folder. Do not overwrite the
baseline.

1. Retain the original report, date, identities, scores, coverage,
   and findings. Do not silently rewrite earlier ratings. Do not
   write into the baseline directory.
2. Inspect current sources and draft the new rationale before
   focusing on numerical deltas.
3. Record additions, removals, renames, and changed boundaries.
   Keep a matched-project comparison separate from an expanded
   inventory.
4. Explain each material score change:

| Project | Dimension | Baseline | Current | Delta | Comparability | Evidence and reason |
| --- | --- | ---: | ---: | ---: | --- | --- |

Reason is one or more of: product or presentation improvement,
regression, new evidence about unchanged behavior, changed
comparison landscape, changed audience or scope, reviewer
calibration or methodology change.

A one-point change is a directional editorial judgment unless the
evidence is particularly clear. Show stable scores when the
evidence does not justify a change. When both sides are NR, write
the delta as `n/a`. Do not write `0`. Zero implies a measured
absence of change. Both dimensions remain unassessed.

5. Recheck each prior material finding. A finding can resolve
   without a score change. A score can change because the evidence
   base improved.

Treat completion notes as claims to verify. Do not reward task
count. Judge whether the underlying user problem was addressed.

A name change alone must never change a score or imply that a
finding was resolved.
